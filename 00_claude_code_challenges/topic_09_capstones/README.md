# Capstones — Beginner Level Finale

Two projects that use EVERYTHING from Topics 1-8. Do them after
finishing the topics (or at least Topics 5, 7 and 8).

| Capstone | Spec | Flavour |
|----------|------|---------|
| A | `capstone_a_wordle.md` | game logic, string feedback, stats |
| B | `capstone_b_console_bank.md` | menus, nested dicts, validation |

Pick your order — B is closer to your infra world, A has the
trickier single algorithm (the repeated-letters rule).

Create one folder per capstone when you start:
`capstone_a_wordle/` with `main.py` + `words.py`, etc.

Rules for both:
- Only days 1-14 Python (no OOP, no file I/O, no try/except).
- Every number read from the user goes through your get_int (8.1).
- Functions return; only the outer layer prints.
- Commit early, commit often — capstones are multi-session work,
  and your PR history should show the build-up.
